# Local SEO Prospect Tracker

A browser-based tool for organizing Local SEO prospect research, recording findings, and tracking supporting evidence.

## Features

- Organize prospect research findings.
- Record observations, implications, and next actions.
- Store evidence URLs and verification status.
- Export research findings to CSV.
- Preview selected homepage information for research purposes.

## Project Status

This project is in early development. Features and workflows may change as testing continues.

## Intended Audience

Independent Local SEO consultants and practitioners who want a more structured approach to prospect research.

## Important Notes

Research observations should be manually verified before making SEO recommendations. The tool does not guarantee search rankings or business outcomes.
